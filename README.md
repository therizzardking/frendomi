Capstone Project Milestone 3 - 

This is a web app designed to help people find friends in their local area
and connects people based on common interests

When first starting with the app, the user  is taken to /signup, where they are asked for a username, email, and a password, and the same password a second time to ensure they entered it correctly. After completing this, he clicks on the login option and enters the same information he just used, and is brought to the homepage
